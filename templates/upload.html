Add statement PDFs

Upload any of the 4 statement types — HSBC Current Account, HSBC Credit Card, Halifax Current Account, or Barclaycard. You can select several PDFs at once (even a mix of different types); the system reads each one to work out which type it is, extracts every transaction, categorises it the same way as the rest of the dashboard, and merges it into the shared history — each file gets its own success/error message below. Uploading the exact same statement twice is safe — it's recognised and skipped rather than double-counted.
