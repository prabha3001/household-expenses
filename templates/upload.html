Add statements

Upload any of the 4 statement types — HSBC Current Account, HSBC Credit Card, Halifax Current Account, or Barclaycard. You can select several files at once (even a mix of different types); the system reads each one to work out which type it is, extracts every transaction, categorises it the same way as the rest of the dashboard, and merges it into the shared history — each file gets its own success/error message below. Uploading the exact same statement twice is safe — it's recognised and skipped rather than double-counted.

Supported file types: PDF (most reliable — the 4 formats above are read exactly), CSV / Excel exports from your bank (matched by column headers like Date/Description/ Amount or Debit/Credit), Word documents (reads a table if there is one, otherwise scans the text), and photos or scans (JPG/PNG) via text recognition. CSV/Excel is just as reliable as PDF when the file has a proper header row; Word-without-a-table and photos/scans are best-effort — check the results below and re-upload a clearer file if a payment looks missing.
